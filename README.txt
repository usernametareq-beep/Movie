# Bangla Movie House Project

## বৈশিষ্ট্যসমূহ:
১. ওয়েবসাইটের নাম: Bangla Movie House
২. আপনার ছবির অ্যাডমিন প্যানেলের হুবহু ডার্ক ও গোল্ডেন থিম ডিজাইন।
৩. ক্যাটাগরি যোগ এবং মুছে ফেলার সুবিধা।
৪. মুভি **Add**, **Edit** এবং **Delete** করার পূর্ণাঙ্গ ফিচার।
৫. একটি মুভিতে একাধিক ভিডিও লিংক (Multiple Links / Server Links) যোগ করার সুবিধা।
৬. লোকাল হার্ডডিস্ক (Local Disk File) থেকে ছবি ও ভিডিও সরাসরি ফাইল অপশন থেকে আপলোড করার ব্যবস্থা।

## রান করার নিয়ম:
১. ফাইলটি Extract করুন।
২. টার্মিনালে প্রজেক্ট ফোল্ডারে ঢুকুন: `cd bangla-movie-house`
৩. প্যাকেজ ইনস্টল করুন: `npm install`
৪. রান করুন: `npm start` (অথবা `node server.js`)
৫. সাইট দেখুন: http://localhost:3000
৬. অ্যাডমিন প্যানেল: http://localhost:3000/admin
